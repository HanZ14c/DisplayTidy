# 开发里程碑

本计划按依赖顺序推进。M0 是可行性检查，M1–M3 构成第一版；M4–M5 是后续增强。所有状态初始为未开始，不使用未经验证的工期承诺。

| 阶段 | 交付物 | 状态 |
|---|---|---|
| M0 | 显示器与随航 API 可行性原型 | 完成：当前设备核心可行性通过；扩展验证列入 M3 |
| M1 | 菜单栏应用与手动对齐 | 进行中：菜单栏入口与可选参考屏四周 12 种对齐已实现，完整预览和识别待实现 |
| M2 | 布局保存、匹配与恢复 | 未开始 |
| M3 | 错误处理与第一版验收 | 未开始 |
| M4 | 暂缓：自定义拖动不在当前范围 | 未开始 |
| M5 | 可选的自动恢复 | 未开始 |

## M0：验证核心能力

目标：在投入完整界面前，证明目标 Mac 上的显示器位置功能可用。

范围收口：以当前设备的关系式排列核心可行性为 M0 验收。非主屏外接屏、有线/无线切换、真实提交失败或中途断连、新版 Sandbox 关系保存/载入移至 M3，尚未验证，不宣称通过。

工作：

- 建立最小原生 macOS 项目，记录开发环境与目标系统版本。只提供诊断窗口和命令行入口，不提前做菜单栏、收藏或拖拽。
- 列出活动显示器的 ID、名称、bounds、主屏及可获取的匹配信息。
- 以 `.forSession` 把指定扩展屏移动到主屏下侧左对齐、居中或右对齐，并保存明确关系；尺寸变化时重新计算。
- 每次操作检查 API 返回结果，并记录请求坐标、错误码和重新读取的实际位置。
- 将最后一次成功应用的关系原子保存；重启恢复选择，不自动移动。旧快照不再参与流程。
- 实测外接屏、随航，以及拔插、睡眠唤醒、有线/无线重连前后的 UUID、名称、vendor/model/serial 和尺寸。身份信息只作为诊断证据，不预设稳定性。
- 验证实际权限和 App Sandbox 设置；记录限制，不凭猜测关闭所有安全设置。

验收：

- [x] 随航屏可枚举、按关系对齐并重新读取核对。（普通版新流程通过；App Sandbox 版旧位置提交流程通过，新关系保存流程仅构建与自检通过）
- [x] 记住最后一次成功应用的关系，重启恢复选择且不自动移动。（普通版已实测）
- [x] 尺寸变化后按关系重新计算。（计算自检通过；用户确认修改分辨率后仍可使用，未记录具体前后尺寸）
- [x] 错误反馈、非法布局拒绝、事务取消和结果核对已实现。（非法布局自检通过；真实系统失败场景列入 M3）
- [x] 睡眠唤醒后可继续使用，手动移动后可重新应用程序对齐关系。（用户实测确认）
- [x] 写明哪些身份信息重连后稳定，哪些未验证。（随航一次重连 UUID 一致、ID 改变，其他情况见记录）
- [x] 有可执行的原型和简短设备验证记录。（见 README.md、M0-VALIDATION.md）

如果随航不可用，不宣称完成随航支持；先定位限制并决定是否缩小范围。这个阶段不做拖拽、精美界面或自动连接随航。

当前支持拖动示意框吸附到程序提供的 12 种固定对齐方式；不实现任意坐标拖动、偏移或关系推断。固定候选吸附交互归入 M1，不提前实现本阶段的自由拖动。

## M5：连接后的自动恢复

目标：屏幕组合稳定后，可选地恢复指定布局。

工作：

- 每个布局提供自动恢复开关，默认关闭。
- 合并连接、断开和配置变化事件，等待状态稳定后重新枚举。
- 只有屏幕匹配唯一、布局合法且当前无用户操作时才自动应用。
- 区分自身应用和外部变化，避免循环。
- 同一屏幕组合有多个候选布局时，由用户指定自动恢复项。

验收：

- [ ] 连接目标屏幕组合后，只应用一次指定布局。
- [ ] 自己的布局提交不会再次触发自动应用。
- [ ] 用户手动调整布局时不会被持续抢回旧位置。
- [ ] 匹配不明确或提交失败时停止自动操作，并显示可理解的状态。
- [ ] 关闭开关后不自动修改排列。

## 每个阶段的 vibe-coding 约定

一次只实现一个 milestone。编码前读取 PROJECT.md 和当前阶段，检查现有代码与目标 SDK；不要提前实现后续阶段。API 名称、可用性和权限以 Apple 文档、当前 SDK 和真实运行结果为准。

阶段结束时交付：实际改动、相关检查结果、真实设备验证结果、已知限制。只有满足验收标准才更新状态；未完成项目保持未完成。

可用的起始提示词：

> 阅读 PROJECT.md 和 MILESTONES.md，先执行 M0。使用原生 Swift 和系统框架，实现最小可运行原型。优先验证外接屏与已经连接的随航屏能否读取、移动和恢复。不要提前开发完整界面或自动恢复，不引入不必要的第三方依赖。实现后运行可执行的检查，列出仍需真实设备验证的项目，不将未测试行为标记为通过。
